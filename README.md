# leonardovilla.github.io

Portfólio técnico de Leonardo Villa — página estática (HTML/CSS/JS puro, sem
build step) publicada via GitHub Pages, centralizando os projetos mais
representativos do meu trabalho como desenvolvedor full-stack.

Site: https://leonardovilla.github.io/

## Stack da página

HTML, CSS e JavaScript vanilla. Sem framework, sem etapa de build — o GitHub
Pages serve o conteúdo do branch `main` diretamente.

## Estrutura

```
index.html          # página única: hero, stack, projetos, contato
assets/
  style.css          # tema claro/escuro (prefers-color-scheme + toggle manual)
  script.js          # toggle de tema com persistência em localStorage
  img/               # screenshots dos projetos
```
